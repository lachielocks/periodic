# Periodic

An interactive periodic table of all 118 elements — with explaining cards, examples of use, and a Three.js atom you can orbit.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- React Three Fiber / Three.js for the interactive atom
